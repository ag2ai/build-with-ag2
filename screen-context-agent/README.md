# ScreenContext Agent for AG2

A minimal AG2 agent that searches your local ScreenContext history through MCP. It demonstrates AG2's stdio MCPToolkit with explicit user opt-in and one allowlisted read-only search tool.

## AG2 Features

- MCPToolkit with MCPStdioServerConfig for a local MCP server.
- Tool allowlisting: only search_screen_history is exposed.
- Agent.ask() for a conversational turn.

## Requirements

- Python 3.11+
- ScreenContext installed and initialized on this computer: https://github.com/ikeikeikeda66/screen-context-agent
- OpenAI API key

## Installation

    python -m venv .venv
    . .venv/bin/activate  # Windows: .venv\Scripts\activate
    pip install -r requirements.txt

Create a ScreenContext client token:

    screen-context mcp-config --client ag2-example --profile standard

Set SCREEN_CONTEXT_CLIENT_TOKEN to the token from the printed MCP configuration, and set OPENAI_API_KEY. The token is a secret; do not commit it. Approve the client in the ScreenContext app on first use.

## Running

By default no ScreenContext tool is registered:

    python screen_context_agent.py

To enable a lookup for this run, explicitly pass --enable-screen-history:

    python screen_context_agent.py --enable-screen-history

Ask a question such as: Find the error message I saw in the browser recently. The agent searches the last 24 hours and returns at most five matches.

Screen OCR is untrusted observed data. The agent is instructed to treat it as evidence, never as instructions. OCR can be inaccurate; verify important details against the original source.

## Configuration

- SCREEN_CONTEXT_COMMAND: executable path; defaults to .venv/bin/screen-context (Windows: .venv\Scripts\screen-context.exe).
- SCREEN_CONTEXT_CLIENT_TOKEN: approved per-client token generated by ScreenContext.
- OPENAI_API_KEY: API key used by AG2.
- OPENAI_MODEL: model name; defaults to gpt-4o-mini.
